# 🎨 Hirst Painting

A **Python Turtle Graphics** project that recreates a colorful dot painting inspired by **Damien Hirst's Spot Paintings**. The program generates a **10 × 10 grid** of randomly colored dots using Python's built-in `turtle` module.

# 📖 Project Overview

This project explores Python's **Turtle Graphics** library by drawing a grid of colorful dots. Each dot is assigned a randomly generated RGB color, creating a vibrant painting inspired by Damien Hirst's famous artwork.

The project focuses on graphics programming, coordinate movement, loops, and random color generation.

---

# ✨ Features

- 🎨 Generates a colorful dot painting
- 🔵 Draws a **10 × 10** grid of dots
- 🌈 Random RGB color generation
- 🐢 Built using Python Turtle Graphics
- ⚡ Fast drawing speed
- 📍 Automatic turtle positioning
- 💻 Simple and beginner-friendly implementation

---

# 🖌️ How It Works

1. Initialize the Turtle screen.
2. Hide the turtle cursor for a cleaner drawing.
3. Move to the starting position.
4. Generate a random RGB color for each dot.
5. Draw a dot.
6. Move horizontally to the next position.
7. After every 10 dots:
   - Move up one row.
   - Return to the left side.
8. Continue until all 100 dots have been drawn.
